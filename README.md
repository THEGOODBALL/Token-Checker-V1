# Token-Checker-V1
check token with info

# *How to use?*

1. Install [python](https://www.python.org/downloads/release/python-3123/)

2. Open setup.bat

3. Put your generated token on tokens.txt

4. Open start.bat and wait for checking!

5. Enjoy!
